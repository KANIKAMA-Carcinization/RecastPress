# RecastPress

RecastPress — WordPress, Recast in Rust.

WordPress本体と実行基盤を一つの製品として統合する、Rust製のWordPress専用アプリケーションサーバー。対象用途と実行経路を絞り、安全で予測可能な運用と、既存サイトの互換性・運用負担の軽減を優先する。速度と資源消費の最適化も目標とする。

最新の設計v0.6では、HTTP・DB・キャッシュ・実行管理に加え、WPの要求解釈・Query・保存・権限・標準コンテンツ処理をRustコアへ移す。内部のPHP実行環境は、既存テーマ・プラグインと、PHPの値・参照・オブジェクトを保つWP互換界面を担う。Wasmは内部の実装手段とし、対応する既存PHP資産を利用者が移植することを前提にしない。現在の実装版は0.5.0で、v0.6のRustコア移植は段階的に実装・検証する。

## ブランチの役割

| ブランチ | 管理する内容 |
| --- | --- |
| `main` | 新旧構成に共通する確定済みのプロジェクト情報、ライセンス、採用ロゴ、除外・改行変換設定 |
| `design/v0.5` | 既存設計v0.45と、新構成の概要・基本・詳細設計v0.5、開発・検証の記録 |
| `dev/v0.5` | 設計ブランチを土台に保存した既存実装と、0.5.0から始める新構成の開発 |
| `design/v0.6` | v0.5の実装・PoC成果を基点にした、Rustコア移植とPHP互換界面の改訂設計v0.6 |

mainには試作コードや未決の設計詳細を入れず、共通部分への変更だけを反映する。設計の変更は設計ブランチへコミットし、実装側へ必要な設計更新を取り込む。実装の変更は実装ブランチへコミットする。

最新設計の入口は [v0.6改訂設計](docs/proposals/2026-11-10-rust-wp-core-v0.6/README.ja.md)。基本設計、PHP互換界面とコアの詳細設計、実装順・受入条件、既存成果との対応をまとめる。設計版はv0.6、次の実装系列の開始版は0.6.0とし、今回の文書改訂では現在の実装版や受入状態を変更しない。

以前の構成は [v0.5設計](docs/proposals/2026-11-01-rust-wp-server/README.ja.md)、元の仕様は [v0.45詳細設計](docs/design.ja.md)を参照。個別機能の実装・検証状態は各ブランチの記録で確認する。

ブランチ分割前のREADMEは、設計・実装ブランチの `docs/history/README.before-branch-split.txt` に保持する。実装由来の出典・検証履歴は、実装ブランチの `NOTICE.md` と対応する記録を参照する。
